# Project Guide

Pagezy is a prototype reading-diagnostic demo and model-evaluation project.
Start with the repository [README](../README.md) for the problem, current
features, setup instructions, Hugging Face Spaces deployment, and limitations.

## Where to go next

- [System architecture](02_system_architecture.md) — application and model
  workflow.
- [Data schema](03_data_schema.md) — formats used by the passage app and model
  training/evaluation scripts.
- [Evaluation rubric](04_evaluation_rubric.md) — intended qualitative rubric
  and a description of the metrics the current scripts actually compute.
- [Licensing notes](05_licensing_and_compliance.md) — separate model, dataset,
  and repository terms to check.
- [Safety and limitations](06_safety_and_limitations.md) — scope and known
  limitations.
- [Deployment runbook](08_runbook_deployment.md) — local usage, Space setup,
  publishing, and troubleshooting.

The `day_plans/` directory is intentionally not part of the public repository.
The scripts and data-generation workflows are documented in the root README and
deployment runbook.
